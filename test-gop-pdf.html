Test gộp ảnh → PDF

Đây là bản test dùng đúng code như 2 trường Hợp đồng và Phụ lục trong tool.
Cách test: bấm Chọn ảnh/PDF → chọn nhiều ảnh (chụp hợp đồng/phụ lục) → kéo để đổi thứ tự nếu cần → bấm “Mở PDF đã gộp”. Nếu ra 1 file PDF nhiều trang đúng thứ tự là chuẩn.
Quy tắc: 1 ảnh hoặc 1 PDF → giữ nguyên; nhiều file → gộp thành 1 PDF.
